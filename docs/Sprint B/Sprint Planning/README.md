## Priorities and dependencies

 1. Everything is dependent on the first User Story. Without the SPA, nothing else can be done: **3.1.1. Set Up SPA**.

 2. After that, the layout must be done: **3.1.2. Create SPA Unified Layout**.
 
 3. For each Sprint A User Story, discussed in **Tasks**, there must be an option on the menu, it's page and feedback: **3.1.3. Show Relevant Menus**, **3.1.5. Provide Pages/Forms** and **3.1.4. Receive Feedback**. They must be prioritized by the following order, asked in 3.1.5.:

    1. US 2.2.7/8/9/10, related to Vessel Visit Notifications

    2. US 2.2.4, related with Storage Areas

    3. US 2.2.12, related with Physical Resources

    4. US 2.2.3, related with Docks

    5. US 2.2.2, related with Vessels

    6. US 2.2.5, related with Shipping Agent Organizations and Representatives

 4. At the same priority and dependency as 3, we can also create the option on the menu and the page for the 3D Visualization Module of the port: **3.3.1. Integrate 3D Visualization Module**.

 5. After the 3D Visualization Module is created, we can do everything else regarding this module: **3.3.2. 3D Representation of Port Structure**, **3.3.3. Display Vessels and Major Resources**, **3.3.4. Render 3D Models Appropriatelly**, **3.3.5. Add Appropriate Lighting** and **3.3.6. Control Camera with Mouse**.
